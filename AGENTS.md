# Standing rules (this repo)

- NO VIBE CODING: read callers and tests first, reproduce and paste the
  failure, state the root cause with file:line, write a failing test,
  make the smallest fix, paste green results. Never guess, stub,
  hardcode, or invent data. Unreproducible = NOT REPRODUCED, no change.
- Use Ponytail (/ponytail-review on every diff) and REA where they apply;
  paste their output. A plugin that is not loaded is BLOCKED, not skipped
