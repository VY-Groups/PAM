# Role console navigation (ADR-0021)
The five job groups of the role-based sidebar with every route's declared any-of operations and the visibility those operations derive per seeded role. The frontend holds no role lists (ADR-0021 D1): a session sees a route when `whoami.operations` intersects its `NAV_JOB_OPS` entry, and each role column shows ✓ when the OpenAPI security scopes grant it at least one declared operation (scope lists = `ROLE_OPERATIONS`, pinned both directions by `tests/test_openapi_contract.py`; `admin` = the admin credential on every admin operation). An empty list is always visible for every signed-in session; open mode (`operations: "all"`) shows everything.
