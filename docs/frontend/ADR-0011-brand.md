# ADR-0011 — Brand: VY-PAM wordmark; interim geometric mark; final logo pending §11 decision

**Status:** Accepted 2026-10-13 (resolves the naming item tracked at
`docs/IMPLEMENTATION_PLAN.md` future list: "the UI brand says AegisPAM,
the product says VY-PAM — pick one")
**Plan ref:** Front-End Rebuild Plan §1 goal 2, §11 open decision 2

## Decision

- **The product and UI brand is VY-PAM.** Every user-visible surface
  (launcher, login, sidebars, titles, hero copy) says VY-PAM; the
  Stitch-era "AegisPAM"/"Stitch" strings are removed from live UI in F0.
- **Interim mark:** the existing neutral shield glyph (blue rounded
  square + white shield, no letterform) ships as
  `frontend/vendor/img/vy-pam-mark.svg` with `alt="VY-PAM logo"`.
  No logo art is fabricated by the agent.
- **Final wordmark/logo remains the user's §11 decision** (created by
  Yash or a designer); when it lands it replaces the interim mark in one
  file plus the tokens. Trademark/licence check for anything generated by
  a tool is the user's call (plan §11, §2 brand row).

## Kept intentionally (documented, not oversight)

- Internal identifiers that are not branding and are contract/test
  locked: sessionStorage keys `aegispam_admin_token`/`aegispam_admin_csrf`
  (renamed when legacy login dies, F5), license-id format
  `LIC-####-AEGIS-SEC-*` (embedded in signed licenses + asserted by
  tests), settings placeholder URLs, the password-denylist entry. See
  `F0_FINDINGS.md` P3 entries.
